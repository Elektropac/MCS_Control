Boot sequence (setup)

Runs once at power-on, in order. Green nodes spawn a task that then runs forever. After setup, loop suspends.

flowchart TD P([Power on]) --> L([log_init]) L --> FS([file_system init]) FS --> CFG([config init]) CFG --> I2C([i2c_init]) I2C --> SMP([sampler_init starts 4 kHz ISR]):::isr SMP --> FG0([flow_guard_init]) FG0 --> DRV([all_drivers_init: I2C chips, OLED, buzzer]) DRV --> SPL([display_boot_splash 2s]) SPL --> DISP([display_start]):::spawn DISP --> CH([channels_setup]) CH --> APPS([start_apps capability router]):::spawn APPS --> NET([network_start_task x4]):::spawn NET --> SER([serial_cmd_start_task]):::spawn SER --> OTA([otaInit and ota_start_task]):::spawn OTA --> END([setup done, loop suspends]) classDef spawn fill:#def7ec,stroke:#046c4e,color:#046c4e classDef isr fill:#ffe3e3,stroke:#b42318,color:#b42318
