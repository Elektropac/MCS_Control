Boot sequence — setup() in main.cpp

Runs once at power-on, in order. Each green "task" box below is spawned here and then runs forever on its own. After setup(), loop() just suspends itself — all work is in tasks + the ISR.

Everything running after boot

Always on

WhatTypePrio / stackJob
sample_isrtimer ISR1 MHz tick, fires every 250 µs (4 kHz)Reads all 8 digital inputs, logs state changes to a ring buffer. Basis for pulse counting + flow guard.
displaytaskP1 4096Owns the OLED. Auto-scrolling carousel (HOME → tanks → pumps → INFO). Alarm overlay takes over on low/overfill.
networktaskP1 8192Ethernet (W5500) + WiFi stack, link management.
web_servertaskP1 8192Serves the web UI (tanks/pumps/setup/test/ota) + /api/function_silo.

bluetoothtaskP1 8192BLE (Niklas) — device access over Bluetooth.
serial_cmdtaskP1 4096Serial debug console (send ? for help).
otataskP1 ~8KIdle until a web/UI request. Fueling-safe gate: never flashes during a transaction.

Started only if the config needs them (capability-driven)
