Boot sequence — setup()

Runs once at power-on, in order. Green nodes spawn a task that then runs forever. After setup(), loop() suspends — all work lives in tasks + the ISR.

flowchart TD P([Power on]) --> L([log_init]) --> FS([file_system.init]) --> CFG([config.init]) CFG --> I2C([i2c_init]) --> SMP([sampler_init
starts 4 kHz ISR]) --> FG0([flow_guard_init]) FG0 --> DRV([all_drivers_init
I2C chips + OLED + buzzer]) DRV --> SPL([display_boot_splash ~2s]) SPL --> DISP([display_start]):::spawn DISP --> CH([channels_setup]) CH --> APPS([start_apps
capability router]):::spawn APPS --> NET([network_start_task x4]):::spawn NET --> SER([serial_cmd_start_task]):::spawn SER --> OTA([otaInit + ota_start_task]):::spawn OTA --> END([setup done - loop suspends]) classDef spawn fill:#def7ec,stroke:#046c4e,color:#046c4e; class P,L,FS,CFG,I2C,FG0,DRV,SPL,CH,END default; class SMP isr; classDef isr fill:#ffe3e3,stroke:#b42318,color:#b42318;

Capability router — start_apps()

No fixed product — reads groups[] from config and starts only the apps the config needs.

flowchart TD R([read config groups]) --> Q{what's in config?} Q -->|probe groups| PR([probes_init + flow_guard + probes task]):::spawn Q -->|pump groups| PU([pumps_init + pumps task]):::spawn Q -->|probe OR pump| RE([rule_engine_init + rule_engine task]):::spawn Q -->|nothing| NN([log: nothing to start]) classDef spawn fill:#def7ec,stroke:#046c4e,color:#046c4e;
